# Entrepreneurship & Leadership Coaching App

This Flutter starter app includes a complete coaching experience for entrepreneurs and leaders, including:

- onboarding and assessment
- personalized scorecard
- coaching dashboard
- AI coach chat
- daily action screen
- weekly challenges
- progress dashboard
- business plan coaching
- leadership plan
- premium gating

## Getting started

1. Install Flutter SDK.
2. Run:

```bash
flutter pub get
flutter run
```

## Project structure

- `lib/app` — app shell and theme
- `lib/core/services` — premium and AI service layers
- `lib/features/coaching` — models, providers, screens, widgets

## Notes

This starter focuses on a complete, scalable architecture and professional coaching UX. It is designed to be extended with Firebase, Supabase, or custom backend APIs later.
