# Android package identifier

The Android namespace and application ID are `com.gladstargtschool6.investlearn`.

When registering the Android app in Firebase, use this exact package name and download a matching `google-services.json` into `android/app/`. If Google Sign-In is enabled, register the SHA-1/SHA-256 signing certificate fingerprints for the relevant debug and release keystores in Firebase Console, then download the updated Firebase config.
